# Solanix Global

Solar generation, recorded so anyone can check it.

Dubai, UAE · [solanix.xyz](https://solanix.xyz)

## What we build

Solanix is a record layer for solar energy. Generation is measured, written so it can be inspected, and settled on BNB Smart Chain. SOLNX is the protocol token: access, fees, and governance.

SOLNX is not a share of a power plant. It is not a promised yield.
